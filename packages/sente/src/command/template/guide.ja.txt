# Sente かんたんガイド

## 1. 始め方
- ログイン: 新しく始めるなら `te register`(メールだけで登録)、キーをお持ちなら `te login`(キーは https://teai.io/dashboard#api-keys)
- 起動: 作業したいフォルダで `te`。あとは「このバグ直して」のように、ふだんの言葉で頼みます
- 最新版にする: `te update`

## 2. モード(どれくらい文脈を持ち歩くか)
- `/mode 節約|標準|たっぷり`(英語 `saver|standard|max`): 節約=12.8万トークンで要約し古いツール出力も整理 / 標準=25.6万で要約(既定) / たっぷり=モデルの文脈窓の上限まで。`/mode` だけなら現在のモードを表示
- `SENTE_MODE=節約 te`: その1回だけモードを指定
- `SENTE_MAX_CONTEXT=400k te`: 要約の閾値を数値で指定(40万トークン)。モードより優先
- 変わるのは要約のタイミングだけで、モデルや料金単価は変わりません

## 3. 使いすぎを防ぐ
- teai ダッシュボード(https://teai.io/dashboard#api-keys)で、APIキーごとに 1分・1時間・1日・1ヶ月 の上限(クレジット)を設定できます
- 上限に達すると Sente は再送せずに止まり、どの上限か・再開できる時刻・`te resume` を表示します
- 上限は次の区切りで自動で戻ります(日・月の区切りは UTC)。作業はセッションに保存されています

## 4. 困ったとき
- 止まった作業の続き: `te resume`
- 動作の確認: `te doctor`
- お問い合わせ・バグ報告: https://teai.io/contact
