ชุดโครงการชุมชนที่สร้างขึ้นบน Sente

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ Sente ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-sente](https://github.com/awesome-sente/awesome-sente) และ [sente.cafe](https://sente.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
